# Raspberry Pi Camera add-on for Home Assistant OS

Live stream from a Raspberry Pi CSI camera plugged into the Pi that runs Home Assistant OS, on
the modern libcamera stack. A thin wrapper around the official
[MediaMTX](https://mediamtx.org/docs/publish/raspberry-pi-cameras) `-rpi` image.

[![Add repository to Home Assistant][repo-badge]][repo-link]

Or: *Settings → Add-ons → Add-on Store → ⋮ → Repositories*, add
`https://github.com/thundo/ha-rpicam-mediamtx`.

| Add-on | |
|---|---|
| [Raspberry Pi Camera (MediaMTX)](rpicam_mediamtx/) | [Documentation](rpicam_mediamtx/DOCS.md) · [Changelog](rpicam_mediamtx/CHANGELOG.md) |

Store images are generated by `tools/render_images.py` (Pillow); edit the script, not the PNGs.
